Merkle-Tree-Based Verifiable Public Data Auditing for Cloud Object Storage Using Smart Contracts

说明基于 Merkle 树与智能合约的云对象存储可验证公开审计

简介论文提出一种云对象存储的公开审计方法：将每个对象的名称与 SHA-256 哈希组成 Merkle 树的叶子，仅把树根存入以太坊智能合约作为公开记录，对象本身仍保存在服务商处。审计者下载对象并用简短的 Merkle 证明重建树根进行比对，从而判定对象完好、被修改或缺失。实验中系统检测出全部单次修改、被篡改对象与被删除对象且无误报；10,000 个对象的证明只需 14 个哈希值，抽检效率与数据集规模无关。

Siri Reddy Tadi, K. Gangadhara Rao, M. Venu Gopalachari 等

Isotaxis: Optimal Asynchronous Byzantine Consensus with Ordering Linearizability

说明Isotaxis：具有排序线性化的最优异步拜占庭共识

简介该论文提出 Isotaxis，一种带排序线性化（OL）保证的状态机复制协议，用于防止交易顺序被恶意操纵（如 MEV 攻击）。其通信复杂度为 O(nℓ+λn²)，在 ℓ≥λn 时达到最优，并且是首个在异步设置中实现排序线性化的协议。实验基于最多 100 个 EC2 实例，结果显示其在 4 至 100 个节点的各种规模下均优于 Pompē。

看点在异步设置下首次实现有序线性化的状态机复制，摘要报告通信复杂度为最优、可容忍拜占庭故障，并称在4至100个节点上的实验中优于Pompē。

Vincent Gramoli, Zhenliang Lu, Qiang Tang 等

Beyond Wasserstein Proximity: Finding Better Transfer Sources

说明超越 Wasserstein 邻近性：寻找更好的迁移源

简介该论文研究迁移学习中如何选择预训练数据源，指出分布上最接近的数据未必最有用。作者在十个 Binance 现货加密货币的五日波动率预测上进行实验，比较六类预测模型，结果显示选择距离较远的源数据在多数模型上带来更好的预测技能。论文强调结论属于固定历史数据集上的探索性发现。

Gordei Verbii, Georgii Killinkarov, Vladimir Yafarov

Performance Guarantees for Permissionless Lending
