Signed but Unbound: The Authority Gap Between Agent Commerce Mandates and Crypto Wallet Signatures

说明已签名却未绑定：智能体支付授权与加密钱包签名之间的权限缺口

简介本文研究人工智能智能体用稳定币付款时，商务协议中规定的商户、订单、金额和支付方与代币合约实际强制执行的字段之间存在的权限缺口。作者定义了九类约束，并针对12种授权配置推导了这些约束，包括Coinbase已部署的Commerce Payments Protocol。在已部署合约代码的本地副本上的全部31,800次试验与推导结果一致。论文还提出了MandateLock这一最小实现，在已部署的代币合约代码上拒绝了全部10,800份被修改的授权书，并接受两个独立签名方的签名。

DispersedBFT: Bottleneck-Free Primary-Backup Consensus using Dispersed Replication

说明DispersedBFT：利用分散复制消除主节点瓶颈的拜占庭容错共识协议

简介本文提出 DispersedBFT，一种类似 PBFT 的高性能共识协议。它通过信息分散（information dispersal）把请求复制的任务从主节点分给各备份节点，从而消除 PBFT 类共识中的主节点瓶颈。作者给出了基于消息认证码与 Merkle 证明（低 CPU 开销）以及基于数字签名（低通信开销）的多种变体。论文报告，在 43 个副本下吞吐量可达每秒 340 万笔交易，比 PBFT 快至 6.2 倍，比 HotStuff 快 2.6 倍。

Nancy Kansal, Celine Sana, Jelle Hellings
