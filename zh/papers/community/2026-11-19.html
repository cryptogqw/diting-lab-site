Probing Ethereum nodes using Sonar

说明用 Sonar 探测以太坊节点

简介Sonar 是 ProbeLab 推出的免费测试工具（目前为测试版），可按需探测单个以太坊节点。输入 ENR 或 libp2p peerID、enode URL 等节点标识后，它会通过 discv5 找到节点，逐个拨号 ENR 中公布的地址，完成 libp2p 或 devp2p 握手，并对共识层节点交换 Status 和 MetaData，再将结果与 ENR 及爬虫记录进行比对。作者希望听取客户端团队和节点运营者的反馈。

Encrypted Account: a PIN that lives in the contract

说明加密账户：把 PIN 放在合约里的智能账户方案

简介Encrypted Account 是一种 ERC-4337 智能账户，用 Zama 的阈值 FHE 加密方式把 PIN 保存在合约内，由合约本身校验并计数猜测次数，不依赖服务器保存 PIN。每次猜测都会先在链上计数，再决定是否可以解密结果，从而限制在线猜测次数。该方案为未经审计的研究原型，代码以 MIT 许可发布。

Reveal a key, not a payload: sending the ePBS payload before the reveal

说明以太坊论坛帖子：先预先发送加密载荷，再只公开密钥

简介该帖讨论以太坊 Gloas（ePBS）中的一种构想：构建者在区块包含其出价后即预先分发加密的区块载荷，揭示阶段只需发送一个 32 字节密钥，以缩短载荷传输所需时间。作者同时指出，这会增加构建者在揭示前的撤回选择权。
