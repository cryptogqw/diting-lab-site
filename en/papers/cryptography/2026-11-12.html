Look It Up: Multi-bit LLM Watermarking via Codebook Search

In brief"Look It Up": Multi-bit LLM Watermarking Using Codebook Search

SummaryThis paper proposes a codebook-based watermarking method for attributing short LLM-generated texts to their source. An n-bit payload is mapped to a longer u-bit codeword, embedded during generation through token-level logit biasing, and recovered by finding the nearest codeword in a secret codebook using Hamming or Levenshtein distance. Experiments report near-perfect recovery of 16 to 24-bit payloads on 200-token generations and strong results on 127-token generations from base models.

Jaros{\l}aw Janas, Pawe{\l} Morawiecki, Josef Pieprzyk

Signed Dyadic Path Encoding for Efficient Non-Interactive Private Decision Tree Evaluation over TFHE

In briefFaster private decision-tree evaluation on encrypted data using signed dyadic path encoding

SummaryThis paper proposes a signed dyadic path-sum encoding for privately evaluating decision trees over TFHE, where a server classifies an encrypted query without learning its input. The method packs the two children of each leaf-parent into one test polynomial, reducing programmable bootstrapping operations from the number of leaves to the number of leaf-parents. The authors extend the approach to gradient-boosted ensembles and report reduced latency on UCI benchmarks at depths 1 to 4 without accuracy loss.

Xintong Song, Yiqiang Zhao, Qizhi Zhang et al.

In briefMobileProbe: Adaptive Security Testing of Phone-Operating AI Agents via Trajectory-Aware Injection

SummaryMobile GUI agents operate phone apps for users by reading the screen, so attackers can hide malicious instructions in ordinary interface content to redirect them. This paper proposes MobileProbe, a red-teaming framework that automatically finds attacker-controllable content, locates vulnerable decision points along an agent's execution path, and iteratively refines context-aware attack payloads. The authors built a benchmark of 83 long-horizon attack instances across 12 mobile apps, each labeled with a confidentiality, integrity, or availability goal. Tested on three representative agent architectures, MobileProbe achieved higher attack success rates than human-written, zero-shot LLM, and adapted prior automated baselines.

CrossPloit: A Benchmark for Cross-Version PoC Migration in Python Web Applications

In briefCrossPloit: A Benchmark for Moving Web Exploit Proofs Across Python Versions

SummaryThis paper introduces CrossPloit, a benchmark of 127 instances across 45 CVEs in Python web applications, testing whether a proof-of-concept exploit for a listed version can trigger the same vulnerability on an earlier, unlisted version. In briefGame-theory study of RIS-assisted challenge-response physical-layer authentication, Part I: perfect channel knowledge

SummaryThis paper studies a physical-layer authentication setting where a user Alice communicates with an authenticator Bob through a reconfigurable intelligent surface controlled by Bob, while an attacker Trudy tries to impersonate Alice by precoding her messages. SummaryThis paper presents ReliaGuard, a watermarking framework for identifying the source of generated or edited images and locating edited regions without a reference.
