Hybrid Quantum–Computational Key Distribution with Reduced Assumptions (Short Paper)

In briefQuantum-computational key distribution with fewer assumptions (short paper)

SummaryThis paper revisits the HM-QCT quantum key distribution protocol from 2025, which relies on a hybrid quantum-computational time-lock model with two assumptions about the attacker. The authors examine two harvest-now-decrypt-later attacks, one using quantum memory and one using classical memory, and show how each is excluded by one assumption. They introduce HM-PRF, a variant that replaces short-term encryption with a locally evaluated pseudorandom function, requiring only the existence of one-way functions.

Kairos: Transactional Security Enforcement at the System Boundary for LLM Agents

In briefKairos: Transactional security enforcement at the system boundary for LLM agents

SummaryKairos is a reference monitor placed at the isolation boundary of an unmodified LLM agent, treating tool calls, shell commands, and agent-written scripts as the same file and network operations. A declarative policy of trusted sources decides most effects deterministically and defers the rest while the agent continues speculatively. A bounded-authority oracle, such as a language model or a human, then releases or refuses deferred effects based on the trace. On AgentDojo, the paper reports attack success falling from 47.0% to 2.7% with benign utility comparable to the undefended agent.
