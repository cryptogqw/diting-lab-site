An Algebraic Polynomial Evaluation Datastructure for Fields of Large Characteristic

In briefAn algebraic data structure for fast polynomial evaluation over large-characteristic fields

SummaryThis paper studies data structures that evaluate a multivariate polynomial at any input point by using random access to a precomputed encoding of the polynomial. The authors construct algebraic curves over prime fields by using the base-β representation of prime field elements, reducing evaluation recursively to points in boxes of decreasing size. The resulting structure greatly improves the dependence of query complexity on the characteristic p and removes p from the data structure size. The variant of the results is enough to disprove Miltersen's conjecture for all finite fields.
