Security of Deep Research Agents: Attack Surface, Defenses, Benchmarks, and Agenda Seeding against Research Planning

In briefSecurity of Deep Research Agents: Attack Surface, Defenses, Benchmarks, and Agenda-Seeding Attacks

Aker: Efficient Two-Party SLH-DSA

In briefAker: An Efficient Two-Party Protocol for Distributed SLH-DSA Signing

SummaryThis paper presents Aker, a maliciously secure two-party signing protocol for SLH-DSA (FIPS 205), the NIST stateless hash-based signature standard, producing signatures that an unmodified FIPS 205 verifier accepts. It combines generic secret-sharing MPC with four optimizations exploiting the SLH-DSA hypertree, including concurrent evaluation of layers, cached public keys, reused upper-layer signatures, and locally sampled one-time subtrees. The authors implement the protocol with a GPU engine for server-to-server deployments, where SLH-DSA-128f online signing takes 2.09 seconds.

Yaron Salman, Ben Riva, Dmitry Kogan

Communication-Efficient Threshold-CKKS Aggregation for Secure Cross-Silo Federated Learning

In briefCommunication-efficient threshold-CKKS secure aggregation for cross-silo federated learning

SummaryThis paper proposes a threshold-CKKS homomorphic encryption protocol for cross-silo federated learning that requires no trusted key-distribution center. It offers Full and Sparse profiles, supporting server-side weighting and dropout-aware reaggregation, and reduces communication through seeded ciphertext reconstruction, selective coefficient transmission, and compressed collective decryption. Experiments on CIFAR-10 and CIFAR-100 show that Sparse substantially lowers online communication compared with FedPHE at matched accuracy, narrowing the communication gap between encrypted and plaintext federated learning.

Jihyung Kook, Dokyeong Kang, Eunsang Lee

CHERI under Fault Injection: An Emulation-Based Security Evaluation of Capability Hardware Enhanced RISC Instructions

In briefCHERI Under Fault Injection: Testing Whether Hardware Memory Safety Holds Up to Faults

SummaryThis thesis examines whether targeted fault injection can defeat the memory-safety guarantees of CHERI, a hardware architecture using capability pointers, in a pure-capability CHERI-RISC-V environment. The author implements fault injection in a QEMU-based emulator and demonstrates four attack scenarios: buffer overflows, control-flow hijacking, data-only attacks, and use-after-free. The results show that a single or small number of targeted faults can succeed, indicating CHERI's guarantees depend on metadata integrity, uninterrupted checks, and revocation bitmap integrity. The thesis proposes mitigations including ECC-protected capability memory, field authentication codes, redundant checks, and revocation bitmap verification.

Eva Sophia Schreyer

Recovery Gone Too Far: Understanding and Repairing Risky Fallback in LLM Agents

In briefOverly Aggressive Recovery: Understanding and Fixing Risky Fallbacks in LLM Agents

SummaryThe paper studies risky fallback, where an LLM agent switches to a substitute tool after an ordinary failure and crosses an action boundary, such as a forced push that deletes another author's commits. An empirical study of 304 scenarios across eight domains and 55 real CVEs found that all four evaluated models exhibit it, with action-boundary violations in up to 96.8% of risky scenarios. The authors propose nrepair, which scores the agent's context before each substitute tool call with a monitor calibrated on normal runs and withholds the call once when triggered. It cuts violations by up to 76.0% across the four models and is similarly effective on Claude Code and Codex.

Liwen Wang, Jiangrong Wu, Zongjie Li et al.

HalluProbe: Exploiting VLM Hallucinations for Backdoor Detection

In briefHalluProbe: Using VLM Hallucinations to Detect Backdoors

SummaryVision-Language Models can be compromised by backdoors planted through poisoned training data. The paper finds that backdoored models hallucinate the backdoor target token more often across diverse inputs, while clean models' hallucinated tokens are random. Based on this, the authors propose HalluProbe, which amplifies hallucinations during decoding and measures how consistent the hallucinated tokens are to identify backdoored models. Tested against six backdoor attacks on three models, it reportedly achieves over 90% accuracy and outperforms existing detection methods.

Ji Guo, Xiaolong Qin, Jin Jiang et al.

In briefLocal order matters: a lightweight CPU-trainable CNN for website fingerprinting on defended Tor traffic

SummaryThis paper studies website fingerprinting attacks that infer which site a Tor user visits from encrypted cell sequences. The authors propose a compact 95,103-parameter 1-D convolutional network, trained on CPU, that processes the raw cell-direction sequence. In briefConcrete quantum circuits and resource estimates for quantum 3- and 4-sieves

SummaryThis paper provides the first complete reversible quantum circuits for the quantum 3- and 4-sieve algorithms for the Shortest Vector Problem, proposed by Chailloux and Loyer in 2023. It designs inner-product predicates in three architectures (low-qubit, balanced, low-depth) and verifies them with exact state-vector simulations. ElevatorII: High-Performance Fully-Static Cross-ISA Binary Translation

In briefElevatorII: A Fast, Fully Static Translator for Running x86 Programs on AArch64

SummaryThis paper presents ElevatorII, a fully static, ahead-of-time binary-to-binary compiler that translates x86 programs to AArch64 without requiring run-time support on the target. It combines superset disassembly, which pre-translates every possible byte interpretation, with observation-guided path selection to create optimized code paths. On 11 SPEC CPU 2026 Integer benchmarks without C++ exceptions, it runs at about 2.5 times native AArch64 time, while output code is about 51 times the size of source-compiled code, with only 2-3% of code being hot.

TrustBound: Mechanized Completeness for Payment Epochs Initiated by AI Agents

In briefTrustBound: Machine-Checked Completeness for Payment Epochs Started by AI Agents

SummaryThis paper studies when a trusted payment service can account for every payment in an epoch and block later payments made under earlier authority. The authors build a Lean model in which operations are recorded before receiving execution authority, with both actions serialized by an admission fence. They prove that the fence fixes a journal covering all modeled effects and outstanding rights, that discharging those rights prevents further effects, and that truthful outcomes yield exact accounting. Concurrent experiments on an executable service also revealed a conflict from reordered provider reads, which serializing retrieval with journal updates removes.

Sandip Nandi, Aishwarya Bose, Apurba Bose et al.

Agent Authenticator: Passkey-Grade, Hardware-Bound Authentication for AI Agents

In briefAgent Authenticator: A hardware-bound login design giving AI agents passkey-level security

SummaryThis paper addresses how AI coding agents authenticate to services such as code repositories, package registries and cloud APIs. Today they use long-lived tokens and API keys that can be stolen through prompt injection or malware on the same machine. The authors propose the Agent Authenticator, which gives agents passkey-like properties: per-service hardware-bound keys, origin binding enforced by the runtime, human-signed scoped mandates, and cross-device approval for high-risk actions.
