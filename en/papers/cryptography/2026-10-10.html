In briefThreshold batch arguments with statistical soundness, enabling obfuscation-free weighted threshold encryption

SummaryThis paper constructs the first threshold batch argument (BARG) for NP statements with statistical soundness, covering an expressive class of trapdoor threshold languages. It is based on circular-secure fully homomorphic encryption, or on witness encryption combined with learning with errors, and the common reference string grows only polylogarithmically in the number of statements k.
