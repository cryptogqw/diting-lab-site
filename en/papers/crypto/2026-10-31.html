Private Accounts Without O(N) Work Through a Hybrid State Model

In briefPrivate accounts with less validator work via a hybrid state model

SummaryThe paper argues that in account-balance-vector designs, hiding which accounts changed forces every private transfer to update global state indistinguishably, so validator work grows linearly with the number of accounts. It proposes separating state representation from execution model, and presents Miden, an Ethereum Layer 2 that uses persistent accounts for programmability, asynchronous notes for value transfer, and client-side proving for execution. Validators verify proofs and update commitments without re-executing transactions, keeping per-transaction work logarithmic in the number of accounts.

Philipp Gackstatter, François Garillot, Marti Górny et al.

Intent-Bound Authorization for Cryptocurrency Withdrawals Under Backend Compromise

In briefAuthorization design to limit crypto withdrawal losses if a backend is compromised

SummaryThe paper proposes the Intent-Bound Withdrawal Authorization Protocol (IWAP), in which an independent enforcement layer checks customer intent, exact transaction effects, fresh workload evidence, and a single-use spending reservation before signing. The authors give conditional arguments for intent preservation, replay resistance, and a fixed-epoch exposure bound. A Python reference monitor tested on synthetic records shows that an independent budget still limits admitted exposure even when the intent authority is compromised. The study evaluates a normalized policy model, not any deployed custody platform.

Toqeer Ali Syed, Asadullah Abdullah Khan, Ali Akrama

Price is Only the Symptom: Understanding and Analyzing Economic-State Manipulation Vulnerabilities in DeFi

In briefBeyond price: analyzing economic-state manipulation flaws in DeFi

SummaryThis paper empirically studies economic-state manipulation (ESM) vulnerabilities in decentralized finance, using 276 real-world attacks and 91 Code4rena audit findings. It proposes a cause-oriented taxonomy with four primary categories and eleven subcategories. The authors find these vulnerabilities often involve violations of protocol accounting, AMM state consistency, and execution-time constraints, not just price manipulation. Among seven evaluated detection approaches, the best identified only 50.4% of real-world attacks.

WhyThe authors propose a cause-oriented taxonomy of economic-state manipulation, evaluated on 276 real attacks and 91 audit findings across seven detection approaches.

Hao Wu, Haijun Wang, Xiapu Luo et al.

On-Chain Behavioral Signatures for Classifying Centralized Exchange Addresses on Ethereum Using Proof-of-Reserves

In briefClassifying Exchange Addresses on Ethereum Using On-Chain Behavior and Proof-of-Reserves

SummaryThis paper builds a classifier for identifying Ethereum addresses belonging to centralized exchanges, using Proof-of-Reserves disclosures to label roughly 3.03 million addresses from 15 exchanges and five non-exchange categories. It derives 58 on-chain behavioral features and tests LightGBM against logistic regression under a leave-one-exchange-out protocol. LightGBM outperformed logistic regression across all five lookback windows, and SHAP analysis highlights gas behavior, ERC-20 token activity, and internal transactions as key signals.

Seongchan Park, Hyunho Jeon, Byungsoo Kang et al.
