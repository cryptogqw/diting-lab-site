Delta N-gram: Forward-Only Continual Writing into a Language Model's Native N-gram Memory

In briefDelta N-gram: Forward-Only Writing of New Information into a Language Model's N-gram Memory

SummaryThis paper proposes Delta N-gram, a method that writes new information into a language model's native hashed N-gram table using forward passes only, leaving the pretrained table unchanged. Updates go into a sparse patch via a small writer that outputs targets and gates, combined with a block-averaged delta rule. Experiments report document-specific memory, better stability over many writes than the plain writer, and drift in some frequently read format rows.

Hao Wu

DLT Terms 100: a learner's glossary based on ISO 22739:2024

In briefDLT Terms 100: A Blockchain Glossary Based on ISO 22739:2024

SummaryThis paper proposes "DLT Terms 100," a glossary intended to improve understanding of blockchain, or distributed ledger technology (DLT). The authors note that gaps between business and technical terminology, and confusion from existing financial terms being reused, hinder comprehension. The glossary is based on ISO 22739:2024 and categorizes terms by how often they appear in representative domestic and international literature and by difficulty level.

Yusuke Kaneko, Takumi Aita, Kohei Ichihara et al.

Temporal Liquidity Crossing for Blockchains: An EIP-1559 Extension for Admission Below the Base Fee

In briefTemporal liquidity matching for blockchains: an EIP-1559 extension admitting transactions below the base fee

SummaryThe paper proposes temporal liquidity markets (TLM), in which transactions seeking early block execution (consumers) fund transactions that accept later execution (providers). In a block-local EIP-1559 extension, providers can be admitted below the base-fee floor, and their gas is excluded from the ordinary demand controller input. The authors state an adversary model with strategic senders and builders and prove eight properties, including validator-checked rule validity, full burning of the base fee, and no subsidy.

Duanyang Dan Guo

Cambium: Participant-Built Commitment Roots for Shared Digital Infrastructure

In briefCambium: Shared Commitment Roots Built by Participants

SummaryThis paper presents Cambium, a permissioned peer-to-peer service in which participants jointly build each cycle's commitment root, so no single party decides which inputs it includes. Fixed-size committees certify inputs, and a recursive-doubling merge spreads root construction across all nodes. A Go prototype on AWS completed cycles in 12 to 148 ms, verified proofs in under 1.5 ms, and showed logarithmic growth.

Mansoor "Manny" Ahmed, Dann Toliver, Ekaterina Pavlova

Who Patches the Lightning Network? Evidence from Release Lines in Gossip, 2023-2026

In briefWho Patches the Lightning Network? Release-line analysis of Lightning gossip, 2023–2026

SummaryThe paper infers which software release line each Lightning node runs by matching the feature bits it announces in public gossip against implementation sources. Analyzing 814 daily graph snapshots from 2023 to 2026, it finds nodes upgrade on release and platform schedules rather than after security disclosures. The authors suggest that platforms packaging releases are the main lever for nodes that lag behind.

WhyInfers release lines from gossip feature bits, validated on daily snapshots, showing platform packaging drives Lightning patching more than disclosures.

Saurabh Kumar
