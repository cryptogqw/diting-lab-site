In briefPhotonZip: A Lifecycle-Aware Compression Framework for HDF5-Based Synchrotron Workflows

Making Every Edit Count: Efficient Binary Edit Correction at the Gilbert-Varshamov Bound

In briefEfficient binary codes that correct edit errors at the Gilbert-Varshamov bound

SummaryThe paper constructs binary codes that reach the classical Gilbert-Varshamov redundancy guarantee for a fixed number of edit errors. For each fixed t≥1 and sufficiently large block length n, the codes correct any combination of at most t insertions, deletions, and substitutions, with redundancy at most 2t·log₂n+O_t(1). For fixed t, construction, encoding, and decoding all run in polynomial time in n, and decoding recovers the original message.

WhyThe authors report polynomial-time constructions attaining the Gilbert-Varshamov redundancy bound for binary codes correcting up to t combined edit errors.

Ryan Gabrys, Shubhransh Singhvi, Eitan Yaakobi

On the optimality of truncation among binary linear sketches

In briefWhy truncation is the best linear sketch for binary data

SummaryThis paper studies inference and function evaluation when a binary input vector is accessible only through a fixed number of parity measurements, called a binary linear sketch. Under a monotonicity condition, the authors show that simply keeping a subset of coordinates is optimal among all linear sketches of the same size. This yields lower bounds for any binary linear sketch. For a distributional graph connectivity problem on n vertices, linear sketches need Θ(n log n) bits for constant error, while a nonlinear protocol needs only O(log n) bits.

WhyThe authors show truncation is optimal among binary linear sketches under monotonicity, and report a Θ(n log n) lower bound for graph connectivity versus O(log n) nonlinear protocols.

Robinson D.H. Cung, Adway Girish, Emre Telatar

A GPU Engine for Sparse Matrix-Vector Products on k²-Tree-Compressed Graphs

In briefGPU engine for sparse matrix-vector products on compressed k²-tree graphs

SummaryThis paper presents a GPU engine that performs sparse matrix-vector multiplication directly on k²-trees, a compact representation of Boolean matrices. It descends the tree level by level, obtaining child positions from a parallel prefix sum or a sampled directory, and processes it in tiles so that temporary memory is bounded by the tree depth. Tested on NVIDIA GB10 and H100 with fourteen graphs of up to 1.2 billion edges, the tree is 2.3–27 times smaller than cuSPARSE's CSR, and a product on the largest graph needs 1.1 GB of device memory, 9 times less than cuSPARSE.

Francesco Tosoni, Gabriele Mencagli

Non-Coherent Over-the-Air Distributed Consensus: Algorithm Design and Power Control Optimization

In briefNon-coherent over-the-air distributed consensus: algorithm design and power control optimization

SummaryThis paper presents a non-coherent over-the-air (NCOTA) consensus framework for distributed average consensus in wireless networks, requiring neither instantaneous channel state information nor phase alignment. It proposes a decentralized projected gradient descent algorithm with row-stochastic mixing (DPGD-RS) and proves its mean-square convergence to the exact average of the agents' initial states. The authors also derive a closed-form bound on the mean-square consensus error and a spectral-reshaping power control scheme that jointly optimizes transmit powers and receive-scaling factors, which converges faster than full-power transmission and spectral-radius-minimization benchmarks in numerical results.
