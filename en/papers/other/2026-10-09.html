In briefHow far Kolmogorov-Loveland randomness is from Martin-Löf randomness

SummaryThe paper studies maps called encodings that send basic sets to clopen sets while preserving uniform Lebesgue measure and disjointness. Neural Polar Codes for Source Coding

In briefNeural polar codes for source compression learned directly from data

SummaryThis paper proposes a data-driven approach to lossless and lossy source compression based on polar codes. Neural polar decoders are trained directly from data to approximate conditional distributions of polar coordinates, without requiring an explicit source model. These learned distributions are used to estimate entropy rates, mutual information, and rate-distortion functions, and to build explicit polar compression schemes. Experiments show that the learned decoders closely match analytical successive-cancellation decoders when those are available, and remain usable when conventional methods are computationally infeasible or the source model is unknown.

CompileMask: Bridging the Gap Between Expressiveness and Efficiency in Attention Masking

In briefCompileMask: A method balancing expressiveness and efficiency in attention masking

SummaryThe paper notes that modern attention workloads need diverse masks depending on runtime metadata, but efficient kernels support only a few patterns. It presents CompileMask, which uses an offline compiler to analyze visibility rules and generate mask-specific preprocessing kernels, with rules written in a region-based DSL called MaskSpec. At runtime, the generated kernel produces a compact Execution Descriptor so the attention kernel can check visibility by comparing element indices against precomputed endpoints. Experiments show up to 3.8× speedup over state-of-the-art methods.
