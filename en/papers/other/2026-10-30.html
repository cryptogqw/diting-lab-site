A Deterministic Commitment Rule over Unstructured DAGs for Optimistic Replication

In briefA deterministic commit rule on unstructured DAGs for optimistic replication.

SummaryThis paper addresses optimistic replication, where replicas execute client requests locally without synchronizing, so results may later be revised and consistency is only eventual. The authors propose a simple framework based on a causality directed acyclic graph, in which each replica represents the object state as a causally ordered set of client operations. The framework includes a deterministic commitment rule that adds virtually no message overhead beyond disseminating submitted operations.
