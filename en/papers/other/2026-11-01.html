Ascend-SpMM: Accelerating Sparse Matrix-Dense Matrix Multiplication on Ascend NPUs

In briefAscend-SpMM: Speeding Up Sparse-Dense Matrix Multiplication on Ascend NPUs

SummaryThis paper presents Ascend-SpMM, a framework for accelerating sparse matrix-dense matrix multiplication, a core operation in graph neural networks and scientific computing, on Huawei Ascend NPUs. It uses a cost model to assign dense regions to the Cube path and sparse residuals to the Vector path, and adds customized kernels that hide memory latency. Reported results show a 12.70 to 20.55 times geometric-mean speedup over the strongest NPU baseline and up to 6.8 times faster end-to-end GNN training. The source code is publicly available.

Jiahe Wang, Yingxia Shao, Shuhan Wang et al.

Improved lower bounds for the kissing number in dimensions 49 to 61

In briefBetter lower bounds on kissing numbers in dimensions 49 to 61

SummaryThis paper gives explicit kissing configurations in R^d for every dimension from 49 to 61, improving the best previously published lower bound in all thirteen dimensions. The configurations come from applying the antipodal block lift of Yang et al. to the 52,416,000-point minimal shell of the extremal lattice P_48p, using a class of 7,193 minimal lines. All results are verified in exact integer arithmetic, and the certificates are released with the code.

Dmitry Kamenetsky

In briefEffect of Reference Signal Choice on Time-Varying 38 GHz Channel Delay Spread

SummaryThis paper examines how the choice of reference waveform affects estimates of temporal dispersion in a time-varying 38 GHz radio channel. Three reference waveforms, generated numerically in MATLAB, measured via a conducted connection, and recorded in an anechoic chamber, are compared using the same wideband measurements taken in a dynamic road environment. Worst-User Outage Probability Minimization in Active RIS-Aided Systems

In briefMinimizing worst-user outage probability in active RIS-aided wireless systems

SummaryThis paper studies how to minimize the outage probability of the worst user in wireless systems assisted by active reconfigurable intelligent surfaces (RIS). Because the objective is discontinuous over an unknown channel distribution, the problem is reformulated using user weighting, a softplus surrogate, and entropic tail-risk aggregation. A data-driven stochastic optimization method based on historical channel samples then jointly optimizes the beamformer and reflection coefficients with projected adaptive moment estimation. Simulation results show the proposed approach's advantages for reliability-oriented active RIS transmission design.

In briefSecrecy sum-rate maximization for RSMA-enabled pinching-antenna systems

SummaryThis paper examines whether competing firms can exchange data in a stable way when their predictive performance affects market share. It models n firms sharing parts of their datasets and uses core stability as the solution concept. Layer-wise CPU-GPU Scheduling for LLM Inference on Memory-Limited Consumer GPUs

In briefScheduling CPU and GPU work layer by layer so large language models can run on consumer GPUs with limited memory

SummaryThis paper addresses running large language models that exceed a single consumer GPU's memory. During decoding, computing some layers on the CPU can take less time than transferring weights, so the method runs those layers on the CPU while the next layer's weights are sent to the GPU in the background. The placement of computation and weight transfers is formulated as a latency minimization problem and solved with an approximation using relaxed temporal constraints. In a consumer desktop environment, the approach speeds up OPT-30B inference by 3.5x over HuggingFace Accelerate and 6.3x over DeepSpeed Zero-Inference.

In briefRandomized consensus that survives mobile crashes via multiple leaders

SummaryThis paper addresses consensus protocols that fail to terminate when an adversary can move between replicas and repeatedly crash one of them. It proposes Multi-Leader Fixed-View Simplex (ML-FVS), in which several leaders may each broadcast a proposal and replicas vote on the set of proposals they have seen. Shared Randomness and Parallel Rounds in Permutation Sampling

In briefShared randomness for sampling random permutations in parallel rounds

SummaryThis paper studies how much shared randomness is needed to sample a uniform random permutation when outputs are produced in parallel rounds. Coordinates committed in the same round are independent given the full history and the current shared choice, and each shared choice is charged the logarithm of its conditional support size, summed along the worst execution path. The authors determine optimal total-variation error under various shared budgets and round densities, and give the optimal cost for exact sampling in Θ(n) rounds.
