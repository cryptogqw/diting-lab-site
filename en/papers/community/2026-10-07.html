Who cleans up the code? SETCODEFROM's dangling bytecode and futureproof design choices

In briefWho cleans up the code? Dangling bytecode and design choices for SETCODEFROM

SummaryA discussion post on the Ethereum Research forum about bytecode that no account references anymore. Breaking the Serial Verification Loop via an Asynchronous Pipeline Consensus Architecture

In briefAsynchronous pipeline consensus to break the serial verification loop

SummaryThis forum post proposes an Asynchronous Pipeline Consensus Architecture that decouples block production from full transaction verification. Nodes propagate a compact payload of 6-byte transaction identifiers to start the next block, while verification of block n is delayed to block n+k via a 1-bit header field. The author asks whether the serial bottleneck can be broken without compromising baseline security and whether the design could apply to Ethereum's account model.
