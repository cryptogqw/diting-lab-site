Probing Ethereum nodes using Sonar

In briefProbing Ethereum nodes from outside with Sonar

SummarySonar is a free beta tool from ProbeLab that tests a single Ethereum node on demand. Given an ENR or other node identifier, it finds the node over discv5, dials each advertised address, and runs the libp2p or devp2p handshake. For consensus-layer nodes it also exchanges Status and MetaData, then compares the results with the node's ENR and past crawl data. The authors ask client teams and node operators what else a probe should check.

Encrypted Account: a PIN that lives in the contract

In briefEncrypted Account: a smart account that keeps its PIN inside the contract

SummaryEncrypted Account is an ERC-4337 smart account that stores a PIN inside the contract, encrypted under Zama's threshold FHE, so no server holds the PIN. The contract checks each guess and counts attempts on-chain before the result can be decrypted. It is a research prototype on Sepolia, unaudited and released under the MIT license.

Reveal a key, not a payload: sending the ePBS payload before the reveal

In briefEthereum research forum post: sending an encrypted ePBS payload early and revealing only a key

SummaryThis post proposes a change to Gloas (ePBS) in which the builder sends an encrypted payload once a valid block includes its bid, so that the reveal only needs a 32-byte key. The author argues this recovers transfer time lost while the builder waits to reveal. The post also notes that it increases the builder's option to withhold.
