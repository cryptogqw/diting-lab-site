Do bid cancellations matter?

In briefDo bid cancellations matter? A discussion of whether proposers will respect cancelled bids under ePBS.

SummaryThis discussion examines whether Ethereum proposers under ePBS will keep respecting bid cancellations, meaning they sign each relay's latest bid rather than the highest. The authors propose a common-value auction model and analyze header logs from the Ultrasound, Titan and bloXroute relays.

Post-quantum DAS with improved provable security

In briefPost-quantum data availability sampling with tighter provable security

SummaryThis post proposes a modified version of a post-quantum DAS scheme that has a tighter provable security bound, giving a higher concrete security level but lower efficiency. The original bound contained a square-root term that weakened the security level, which the modification removes. The authors also prove the tighter bound in Lean.

Checking transaction inclusion against an untrusted explorer API: how much proof of work is enough?

In briefVerifying transaction inclusion against an untrusted explorer API and how much proof of work is needed

SummaryThe author, who maintains btc-toolkit, a stdlib-only Python Bitcoin CLI, seeks design feedback on its verify command, which checks transactions, Merkle proofs, and block headers from an untrusted Esplora/Mempool API without a node. Headers with difficulty of at least 50 T are reported as verified, a fixed threshold the author questions as difficulty changes. The post asks whether a better anchor, checking descendant headers, or timestamp checks would strengthen the verifier.
