A STARK proof of Bitcoin's UTXO set at block 972,500, with circuits proven in Lean

In briefA STARK proof of Bitcoin's UTXO set at block 972,500, with circuits proven in Lean

SummaryThe author shares a personal project on Delving Bitcoin that uses STARK proofs to verify parts of Bitcoin consensus. A 1.6 MB proof file is said to verify in a browser in about half a second, covering a header chain from genesis, a replay of blocks 935,001 to 972,500, and the UTXO set after block 972,500, whose hash matches Core's hash_serialized. Scripts and signatures are not covered, and the coin set relies on the same trust as assumeUTXO snapshots.

BIP Draft Post-Quantum Address Format (bc1z) using ML-DSA-65

In briefDraft proposal for a post-quantum Bitcoin address format (bc1z) using ML-DSA-65 signatures

SummaryThis forum post shares a draft Bitcoin Improvement Proposal for a new bc1z address format that uses ML-DSA-65 (FIPS 204) post-quantum signatures. The address commits to a SHA-256 hash of the ML-DSA public key, which is revealed only in the witness at spend time, similar to P2WPKH. The author requests community feedback on address design, parameter choice, soft fork deployment, and migration paths for existing UTXOs.

[RFC] WARCoin: Deterministic 1:1 USD Stablecoin via Serialized 7-Day Color Ring Buffers and Burn-on-Egress Invariants

In briefWARCoin: A Proposed 1:1 USD Stablecoin Using Serialized 7-Day Color Buckets and Burn-on-Egress Rules

SummaryThis request for comments proposes WARCoin, a deterministic 1:1 USD stablecoin designed to prevent infinite-mint bugs, cross-collateral contagion, and replay attacks. It accepts only USD deposits, burns serial numbers when funds leave, and organizes issuance into seven daily color buckets of 1,000 serials each. A global supply cap of 10^9 serials is enforced, with minting paused when limits are reached.

More Meters or More Prices? One- vs. Multi-dimensional Fee Mechanisms on Ethereum

In briefMore Meters or More Prices? Comparing One- and Multi-dimensional Ethereum Fee Mechanisms

SummaryThis Ethereum Research forum post compares one-dimensional fee mechanisms with the multidimensional fee market proposed in EIP-7999. The author raises the target-to-limit ratio of a normalized benchmark to 4/5 and replaces the EIP-1559 update rule with an EIP-4844-style update, measuring execution gas, state growth, and near-limit blocks. Higher ratios increase execution but push state growth away from its target and raise congestion. The EIP-4844-style update allows lower fees and more execution, but with more congestion.
