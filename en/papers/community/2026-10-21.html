Cost-Bounded Transaction Filtering Language

In briefCost-bounded transaction filtering language for node policy

SummaryThe author designed a transaction filtering policy language and implemented it in satd, a Rust Bitcoin full node. It lets operators choose which transaction shapes to relay or include in block templates without affecting consensus correctness. Matching transactions are quarantined rather than rejected, keeping policy visible and tunable. If rules might catch important protocol transactions such as Lightning channel closures, the node refuses to load the filter by default.

Evaluating Deterministic BFT Finality within a Confidential UTXO State Machine

In briefTesting deterministic BFT finality in a confidential UTXO blockchain

SummaryThe author presents FinalisCore, an open-source Layer-1 blockchain written from scratch in C++, and requests technical feedback on its state transition model. Blocks become final in 32-block epochs once a committee quorum signs them, and transaction amounts are hidden using Pedersen commitments from secp256k1-zkp. Open questions cover wallet handling during rapid committee changes and the CPU cost of batch range-proof verification, and the live testnet is explicitly non-commercial.
