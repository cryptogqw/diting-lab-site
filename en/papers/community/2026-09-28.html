Bitcoin-rs: an independent Bitcoin full node written in Rust

In briefbitcoin-rs: An Independent Bitcoin Full Node Written in Rust

SummaryThe author shares early work on bitcoin-rs, an independent Bitcoin full node written in Rust, similar to btcd, built to explore architectural and performance changes that are hard to try within Bitcoin Core. It integrates a UTXO set and a read-only Esplora-compatible script index, uses a modular design with contained failure boundaries, and supports script validation either natively or via libbitcoinkernel. The project also plans a verification framework using multiple independent references to make correctness and performance results reproducible against Bitcoin Core.

PQ anonymity for Stealth Address Protocol

In briefPost-quantum anonymity upgrade for the Stealth Address Protocol

SummaryThis is the second post in a series on upgrading the Stealth Address Protocol (SAP) to post-quantum security. It proposes replacing ECDH with the ML-KEM key-encapsulation mechanism to protect payment discovery and recipient unlinkability against quantum attackers. The author notes that a quantum attacker observing public on-chain registry and announcement data could recover secrets and gain scanning and spending access. The post also outlines the ML-KEM key generation, encapsulation and decapsulation steps and the byte sizes of its three parameter sets.

Forwardable Peerswap Incentives, And Closing Surreptitious Communications Tunnels

In briefForwardable Peerswap incentives and closing covert communication tunnels

SummaryThis Delving Bitcoin post proposes Forwardable Peerswaps, a method for managing Lightning Network liquidity. The author compares it with splicing, arguing it is more incentive-compatible because a swap succeeds only if the counterparty actually has the inbound capacity. The author also argues it offers better privacy, since participants forward swaps using only their local channel information.
