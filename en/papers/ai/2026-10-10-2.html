VitaBench: Memory Lifecycles Beyond Retrieval

In briefVitaBench: A Benchmark for Memory Lifecycles Beyond Retrieval

SummaryThis paper argues that existing long-term memory benchmarks for language agents mainly test whether past information can be retrieved, while not directly evaluating whether a memory should stay exact, be compressed, consolidated, or deleted.
