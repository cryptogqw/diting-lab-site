DPMA: Learning to Compress Mixture-of-Experts Models

In briefDPMA: A Learned Method for Compressing Mixture-of-Experts Models

SummaryMixture-of-Experts models are computationally efficient but need large memory to store all experts, which limits their use on constrained hardware. This paper introduces DPMA, a retraining-free compression method that uses gradient descent to jointly learn how to prune, merge, and absorb experts and how to allocate experts across layers under a global budget. Tested on four MoE models, eight multiple-choice benchmarks, and five compression ratios, DPMA achieves the highest benchmark-averaged accuracy on each model among the methods evaluated. At 75% expert reduction, it beats the strongest baseline on every model, by up to 6.7 percentage points.

Jon Irureta, Jon Imaz, Philipp Wiesner et al.

In briefRef-YOLO-World: Efficient Referring Expression Comprehension on Edge Devices by Decoupling Text Computation

SummaryThis paper proposes Ref-YOLO-World, which separates text-side computation that depends only on the referring expression from image processing and reuses those outputs across video frames. In briefSUPERVISE: A Standard, Reproducible Framework for Evaluating Superpixel Segmentation

Code, label maps, and results are publicly released.

Budgeted Subset Selection with a Transferable Learned Value Model

In briefChoosing a Subset of Items Using a Reusable Learned Value Model

SummaryThis paper presents SALVES, a framework that splits subset selection into two parts. A value model is first trained with supervised learning to predict how much each candidate would add to the current selection, and a selection step then picks the subset from these predictions, typically using simulated annealing with a diversity penalty. The value model transfers to new classes, pretrained networks, datasets, sensors, and from synthetic to real data. Across four applications, SALVES matches or outperforms application-specific baselines on average.

Jade Lejeune Herman, Johan A.K. Suykens, Peter Goos

Average-Depth Variable Execution via Request-Local Token Routing

In briefA method for variable per-token layer execution in LLM inference under average-depth budgets

SummaryThe paper introduces AVERT, which lets each token in a large language model run a different number of layers so that each request's average executed depth matches its budget. A router decides per token and per layer whether to run the Transformer block, and skipped tokens pass through a lightweight residual adapter without writing a key/value entry at that layer. Across three LLaMA backbones, six quality metrics and 13 budgets, the authors report AVERT is best or tied in 206 of 234 comparisons. Mixing budgets within a batch reduced time per output token by 4.3% to 21.2%.

Pengjie Zheng, Mengwei Xie, Huan Yang et al.

In briefCRAFT: Reusing Longer Shared Patterns to Compress Reasoning Training Data Efficiently

SummaryThe paper introduces CRAFT, a method for compressing chain-of-thought reasoning traces offline to create shorter training targets. It abstracts problem-specific details into slots, identifies partially lexicalized expression templates, and groups wording variants into families. Each family's representative is compressed once, and the shared edits are applied to every occurrence. In briefFastD4RT: Training-Free Speedup for Dynamic 4D Reconstruction and Tracking

SummaryThis paper analyzes the inference cost of D4RT, a query-based model that encodes a video into a scene representation and decodes point queries, and finds that much of its computation is redundant. The authors propose FastD4RT, a training-free method that encodes and decodes only at sparse anchors, recovers other outputs by interpolation, and decodes remaining queries against a shared token set chosen once per segment.
