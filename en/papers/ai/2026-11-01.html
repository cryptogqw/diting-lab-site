Object-Only Is Not Context-Free: A Counterfactual Diagnostic for Context Removal in Object Retrieval

In briefObject-Only Is Not Context-Free: A Counterfactual Test for Background Removal in Object Retrieval

SummaryThis paper checks whether object-centric retrieval, which masks the background before pooling features, really produces a descriptor that reflects only the object. The authors introduce the Keyhole Aperture Probe (KAP), which keeps the object region fixed and varies only the outside pixels to measure a backbone's context dependence.
