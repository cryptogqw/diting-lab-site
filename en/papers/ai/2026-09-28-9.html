In briefEfficientAgent: When KV cache offloading helps concurrent LLM agents

SummaryLLM agents resend their full conversation each turn, so serving systems cache key-value state and offload it to host memory when GPU memory runs short. The paper finds that offloading's benefit varies across deployments and depends on whether the host tier can hold the reusable context of the whole agent pool, called the reuse working set.
