HCENC: How to Design an Efficient Committing Beyond-Birthday-Bound Accordion from a Block Cipher with n-Bit Blocks and Keys

説明HCENC：n ビットのブロック暗号から効率的なコミット可能な生日限界超えのアコーディオン方式を設計する方法

要約本論文は、可変長入力のための可調整暗号モード（アコーディオン）である HCENC を提案します。HCENC は HCTR を一般化したもので、n ビットのブロックと鍵をもつブロック暗号、n ビット AXU ハッシュ関数、CENC の鍵ストリーム生成器から構成されます。理想暗号モデルにおいて、約 2^n/w ブロックまで強い可調整擬似ランダム置換であることを証明しています。また、AES を用いた具体的な実装で 116 ビットの CMT-1 と CMT-4 が得られることを示しています。

注目点新規性は、n位ブロック・鍵の暗号から承認型のbeyond-birthday-bound accordionを構成し、理想暗号モデルで強い可調疑似ランダム置換を示す点にある。摘要は計算コストの小ささと機械検証済みの証明に言及している。

Roberto Avanzi

Exact Post-Quantum Security Analysis of Ascon Authenticated Encryption under Nonce Misuse

要約本論文は、NIST SP 800-232として標準化された軽量認証暗号Ascon AEADを、ノンス再利用の状況下で量子ランダム置換モデルにより耐量子安全性の観点から分析している。機密性と真正性について、min{2^(κ/2), 2^(c/3)}までの安全性を証明し、鍵長への依存を従来の2^(κ/3)から2^(κ/2)へ改善した。また、量子探索を用いた攻撃を構成し、この安全性上界が指数部において厳密であることを示している。

注目点新しい表現によりAscon AEADを初期化関数とtweakable block cipherに分解し、Hosoyamadaの鍵長依存を改善、対応する量子攻撃でタイトな界を示すと報告。

Rentaro Shiba, Tetsu Iwata

Extending the Security of Arithmetic Masking to All Finite Cyclic Groups via Fourier Analysis

説明フーリエ解析による算術マスキングの安全性の全有限巡回群への拡張

要約本論文は、秘密を模Nの整数の各シェアに分割したときの、シェアのハミング重みの同時分布と、秘密が一様なときの分布との全変動距離を扱う。著者らは、任意のN≥2と固定されたk≥3について、この距離が秘密の値によらず一様に、nの特定の負のべき乗で減少することを示す。ここでnはNの二を底とする対数の切り上げである。証明はブール立方体上のフーリエ解析と、{0,…,N−1}を長さが二のべき乗の区間に分解する手法を用いる。これによりBiswasらの研究にあった、法が二のべき乗に近いという制限が取り除かれ、一般上界の指数は維持される。

注目点算術マスキングの安全性境界を、二のべき近傍の法から全ての有限巡回群へ拡張した。ブール立方体上のフーリエ解析と二のべき長の区間分解を用い、全てのNに対する全変動距離の界を与えたと報告。

Near-n-Bit Preimage and Second-Preimage Security of the JH Mode

説明JH モードの近 n ビット原像・第二原像安全性

要約本論文は理想置換モデルにおいて JH モードの原像耐性と第二原像耐性を再検討し、従来の直接的な境界が誕生日のスケルトンにとどまっていることを示す。メンガーの定理とポテンシャル関数を用いて新たな境界を導き、2^64 ビット以下のメッセージについて約 2^(n-2√(2n)-O(log n)) 回の問い合わせまで無視できる優位性を与える。JH-512 の幅では、重みなし証明書により原像成功確率が 2^431 回まで 1/2 未満であることを示す。Lean 4 による形式化も含まれる。

注目点理想置換モデルでJHモードの原像・第二原像の安全性を、Mengerの定理とポテンシャル関数により誕生日限界からほぼn ビットの水準へ改善し、Lean 4で形式化している。

Changlun Li, Hongli Li, Yijun Yuan ほか

On Perfect Additive Randomized Encodings

説明完全な加法的ランダム化符号化の存在をめぐる否定的結果

要約本論文は加法的ランダム化符号化（ARE）を扱います。各入力を局所的に符号化し、その符号化の総和だけから関数値を復号しつつ、入力について他に何も漏らさない仕組みです。著者らは、有限アーベル群上のOR関数について、完全な安全性と完全な正しさを併せ持つAREが存在しないことを示します。また素数p>2のZ_p上のXOR関数についても、符号化確率が有理数であるという仮定の下で同様の結論を示します。さらに、特定の制約の下で完全な正しさを持つ不完全安全なAREや、ヒストグラム上で非自明な誤り率を持つ完全安全なAREの排除も扱い、シャッフルモデルのプロトコルにも同じ結果が及ぶことを述べています。

注目点新規性は有限アーベル群上でORの完全ARE、ZpでのXORの完全AREの存在を否定する点にあり、証明による結果で、分野の理論的理解に寄与する。

Yuval Ishai, Eyal Kushilevitz, Sahar Alon Yerushalmi

説明一貫性を備えた安定的なプライベート積集合（SPICy）
