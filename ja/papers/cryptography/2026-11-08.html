説明SIExBench：機密情報露出欠陥の自動修復ベンチマーク

要約本論文は、機密情報露出（SIEx）欠陥の自動修復に特化した初のベンチマーク「SIExBench」を提案しています。64 の Python および Java リポジトリfrom得た 161 件の実行検証済みインスタンスを含みます。6 つの修復システムと 3 つの LLM による 18 構成を評価した結果、最良の構成でも解決率は 39.1% にとどまり、失敗例の 62.1% では有効なパッチが生成されたものの機密情報の露出が残っていました。

注目点敏感情報露出欠陥の自動修復に特化した初のベンチマークで、6修復システムと3種LLMの18構成を評価し、最良でも39.1%の解決にとどまると報告。

Mingming Zhang, Xu Wang, Jian Zhang ほか
