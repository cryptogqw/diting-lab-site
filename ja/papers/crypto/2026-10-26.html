Merkle-Tree-Based Verifiable Public Data Auditing for Cloud Object Storage Using Smart Contracts

説明スマートコントラクトを用いたクラウドオブジェクトストレージの、Merkleツリーによる検証可能な公開監査

要約本論文は、クラウドオブジェクトストレージ向けの公開監査手法を提案する。各オブジェクトの名前とSHA-256ハッシュをMerkleツリーの葉とし、ツリーのルートのみをEthereumのスマートコントラクトに公開記録として保存し、オブジェクト自体はプロバイダーに残す。監査者はオブジェクトをダウンロードし、短いMerkle証明からルートを再構築して保存値と照合し、無改変・改変・欠損を判定する。実験では、単一の改ざん、複数の改ざん、削除のすべてを誤報なしで検出し、10,000件のオブジェクトの証明にはわずか14個のハッシュしか必要としなかった。

Siri Reddy Tadi, K. Gangadhara Rao, M. Venu Gopalachari ほか

Isotaxis: Optimal Asynchronous Byzantine Consensus with Ordering Linearizability

説明Isotaxis：順序線形化を備えた最適な非同期ビザンチン合意

要約本論文は、順序線形化（OL）保証を備えたステートマシン複製プロトコル Isotaxis を提案しています。取引の順序操作（MEV攻撃など）への耐性を高めることを目的としています。通信計算量は O(nℓ+λn²) で、ℓ≥λn の場合に最適であり、非同期設定で順序線形化を実現した初のプロトコルとされています。最大100台のEC2インスタンスを用いた実験では、4〜100ノードのすべての規模で Pompē を上回る性能が示されています。

注目点非同期設定で順序線形化を達成した初のSMRとして、最適な通信量と拜占庭耐性を示し、4～100ノードで実験的に検証している。

Vincent Gramoli, Zhenliang Lu, Qiang Tang ほか

Beyond Wasserstein Proximity: Finding Better Transfer Sources

説明Wasserstein 近接性を超えて：より良い転移元の探索

要約本論文は、転移学習で事前学習に用いるデータ源をどう選ぶかを検討し、分布上もっとも近いデータが最も有用とは限らないことを示します。Binance の現物暗号資産10銘柄の5日間ボラティリティ予測で、6種類の予測モデルを比較しています。結果として、ガウス Wasserstein 距離で遠い転移元を選ぶ方が、多くのモデルで予測の相対的な技能を高めました。ただし、本研究は固定された過去データでの探索的な知見と位置づけられています。

Gordei Verbii, Georgii Killinkarov, Vladimir Yafarov

Performance Guarantees for Permissionless Lending

説明許可不要型レンディングの性能保証

要約本論文は、Aave や Compound などのプール型レンディングプロトコルより大幅にリスクが少ないとする貸付プロトコルを提案しています。貸し手と借り手が競争的な金利オファーを出すことで市場金利が決まり、貸付金利は期間中固定されます。さらに担保価値をランダムウォークとしてモデル化し、特性関数とフーリエ反転を用いて清算確率と返済不足確率の厳密な積分表現を導出し、ビットコインを担保とした実証分析を行っています。

Nanqiao Wang, Jia Yuan Yu
