Market Regime-Based Multi-Asset Portfolio Optimization Using Nested Clustered Optimization for Tactical Asset Allocation

説明市場レジームに基づく多資産ポートフォリオ最適化：隠れマルコフモデルで相場局面を判定し、入れ子型クラスタリング最適化を用いた戦術的資産配分の研究です。

要約本論文は、ガウス型隠れマルコフモデル（HMM）による市場レジーム判定と入れ子型クラスタリング最適化（NCO）を組み合わせた戦術的資産配分の枠組みを提案します。レジームはサンプル外で判定されています。インドネシアの国債、LQ45株式、金、為替、ビットコインからなる56か月のサンプル外期間（2021～2025年）で評価され、等ウェイトなど複数のベンチマークと比較されています。レジームを考慮したNCOは最大ドローダウンを4.44%に抑えた一方、レジームを考慮しないNCOはより低いドローダウンと高い累積収益を示しました。著者は、24か月のローリングHMMがレジームを頻繁に切り替えることで、条件付き共分散推定の利点が損なわれると指摘しています。

Supriadi, Bambang Siswoyo

When EVM Defaults Break: Three SDK Patterns for UTXO-Family Wallets

説明EVM の既定設定が通用しない場合：UTXO 系ウォレット向けの SDK 設計パターン3種

要約本論文は、ethers.js や viem などの主流 Web3 SDK が、アカウントモデル、単一の secp256k1 署名者、入力選択を伴わない取引構築を暗黙に前提としており、Nervos CKB の Cell モデルのような UTXO 系チェーンや、secp256k1・WebAuthn・Schnorr など複数の暗号方式が混在する環境では、これらの前提が成り立たなくなると指摘しています。著者は TypeScript SDK の CCC を事例に、リリース履歴と公開 API から3つの繰り返し現れるパターン（容量を考慮した取引組立器、統一署名抽象、ウォレット接続 UI コンポーネント）を抽出しています。UTXO 系台帳と多様なウォレット環境を対象とする SDK に応用できる設計上の知見として整理しています。

Hanzheng Zhang, Hongzhou Chen

Mise-en-Video: Fine-Grained 3D Control for Multi-Shot Video Generation

説明Mise-en-Video：マルチショット動画生成のための細粒度3D制御

要約本論文は、クリエイターが3D空間で複数ショットの配置を設計し、それに対応するマルチショット動画を生成できるフレームワーク Mise-en-Video（MeV）を提案しています。階層的なアテンション機構で物語の一貫性を保ち、3D認識のレイアウトガイダンスでショットごとの正確な空間制御を行います。学習と評価のために、階層的なマルチショットテキストと有向3Dバウンディングボックスを付与した16万本の動画データセットも構築されました。実験では、動画品質、ショット間の一貫性、被写体単位の制御性のいずれにおいても、強力なベースラインを上回る結果が示されています。

Yingshuang Zou, Xiaoyu Shi, Yawen Luo ほか

Proof-of-Machine-Learning-Inference: Mining Knowledge, Not Hashes

説明ハッシュ計算に代えて機械学習推論を行う合意プロトコル（Proof-of-ML-Inference）

要約本論文は、マイナーがハッシュパズルの代わりにユーザーが依頼した機械学習推論を実行する合意プロトコル「Proof-of-ML-Inference（PoML）」を提案しています。推論でハッシュ作業を安全に置き換えるために必要な計算上の前提を定式化し、大規模言語モデルと拡散モデルがそれらを満たすと述べています。プロトコルの安全性はBitcoin Backboneモデルの安全性に帰着させて分析され、シミュレーション環境でブロック生成時間の安定性が評価されています。

Wan Ki Wong, Michele Ciampi, Rik Sarkar
